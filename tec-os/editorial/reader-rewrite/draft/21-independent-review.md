## Ranked findings

1. **P3: the colon test increments A, not D or E.**
   Draft21:197–202 says “Incrementing D” and “incrementing E”. The pass
   record's source-proof row at138 goes further and names “INC D” and
   “INC E”. At ea3ef3d:src/cpm/ccp.asm:231–237 the actual sequence is
   `ld de,(PRGCODE)`, `ld a,d`, `inc a`, conditional branch, `ld a,e`,
   `inc a`, conditional branch. DE is not incremented. The stated success
   and failure ranges are correct, but the purported register trace is not.
   Replace with: “The CCP copies D into A and increments A. A nonzero
   result accepts codes below FF00h. When D is FFh it repeats the test
   with E. A zero result then accepts FFFFh.” Correct the matching pass-record
   row to name the two copies and INC A operations.

2. **P3: COPY prints its count before PRTGO.**
   Draft21:237–239 says “COPY prints its successful count through PRTGO”.
   At ea3ef3d:src/cpm/ccpmut.asm:355–365, PUTSTR prints COPIED and CPHEX
   prints the two count bytes. Lines366–368 load CRLFMSG and jump to
   PRTGO. At src/cpm/ccp.asm:619–629, PRTGO is the entry below ERRGO's
   failure store and prints only the message passed to it. The zero-result
   conclusion is right. Replace with: “COPY prints COPIED and its count,
   then sends the final newline through PRTGO. That entry bypasses ERRGO's
   failure store so the result remains zero.” The pass-record message-path
   proof already distinguishes the skipped store correctly.

3. **P3: the pass record reverses argument-position setup and dispatch.**
   The source-proof row at21-pass-record.md:135 says NOTDRIVE identifies a
   built-in or file “then advances ARGSTRT to the arguments”. At
   ea3ef3d:src/cpm/ccp.asm:403–412, CMDPARSE first parses the command name
   and ARGSTRT is advanced at411. The built-in comparisons follow at415–444
   and file/service dispatch at445–465. Change the row to: “NOTDRIVE parses
   the command name, advances ARGSTRT to the arguments and then selects a
   built-in handler or file path.” The draft does not make this ordering error.
