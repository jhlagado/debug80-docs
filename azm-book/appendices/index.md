# Appendices

Lookup material for the whole AZM series. The first four cover the assembler, the last four cover the Z80 itself.

| | | |
|---|---|---|
| 1 | [Directive Reference](01-directives.md) | Every directive and declaration keyword, with the chapter that covers it |
| 2 | [Expression Operators](02-operators.md) | Precedence, associativity and evaluation rules |
| 3 | [CLI Flag Reference](03-cli-flags.md) | Command line flags and their defaults |
| 4 | [Built-in Functions](04-functions.md) | `sizeof`, `offset`, `LSB` and `MSB` |
| 5 | [Numbers, Notation and ASCII](05-numbers-notation-and-ascii.md) | Hex, binary, decimal, common landmarks and 7-bit ASCII |
| 6 | [Registers, Flags and Conditions](06-registers-flags-and-conditions.md) | Register roles, flag meanings and branch condition codes |
| 7 | [Addressing, Prefixes and Forms](07-addressing-prefixes-and-instruction-forms.md) | Addressing shapes, prefix families and quick instruction-form tables |
| 8 | [Z80 Instruction Reference](08-z80-instruction-reference.md) | Standard and classic-undocumented instructions, searchable |
