# Retired documentation

This directory preserves documentation that is no longer part of the public
Debug80 site. The files remain available for research and may inform later
work, but they do not define current projects or public terminology.

VitePress, the sidebar generator, link checks, symbol checks, and the citation
index exclude this directory.

`nucleus-nvm-publication/` preserves the retired NVM reading edition, its sync
script, and its syntax grammar. NVM is no longer an active Nucleus authority or
publication input.

`nucleus/` preserves the retired Nucleus publication: the Programming Nucleus
course, the Nucleus 0.1 language specification and runtime contract reading
editions, and the scripts that synced and verified them. Basie has replaced
Nucleus as the site's language project, and its book is published under
`basie/`.
