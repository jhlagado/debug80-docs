# Atom Books

The reference manual for **Atom**, the single-pass Z80 assembler whose native
core is itself written in Z80 assembly.

---

## [Atom Book 1 — Assembler Reference](book1/)

Covers installation, source syntax, symbols, expressions, the complete claimed
Z80 instruction surface, data and string directives, host preprocessing,
binary inclusion, diagnostics, artifacts, the command line, and the
programming API.

---

## [Appendices](appendices/)

Quick-reference tables for directives, expressions and numeric forms, command
options, built-in functions, and measured limits.

Atom teaching books can follow the Z80 and algorithmic progression of the AZM
series. The assembler reference comes first because it defines the language
those books will use.
