# Triptych

Triptych provides a Z80 computer environment for running CP/M and its programs.
The browser host lets you work at the CP/M terminal with disk images stored by
the browser.

## Using CP/M

[CP/M essentials](cpm/) introduces the prompt, drives and files used in the
[Programming Skate](../skate/book1/) course. This is the first section of the
planned Triptych documentation.

The [Triptych repository](https://github.com/jhlagado/triptych) contains the
machine implementation and detailed operating guides. Browser deployment and
physical hardware qualification are separate release concerns.
